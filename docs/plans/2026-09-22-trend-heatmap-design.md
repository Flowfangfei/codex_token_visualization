# 趋势视图与时间筛选

- 总览及各数据源共用折线/日历热力图切换；默认折线、近 30 天。范围支持 30/90/180/365 个自然日、全部、自定义闭区间；近 N 天截止浏览器本地今天。
- 模式与范围仅保存为浏览器偏好，不修改导出、原始日账本、累计卡片、额度拟合或模型分布。
- 日历周从周一开始，一格一天。颜色按所选范围最大日 Token 的 25%、50%、75%、100% 划分，图例显示具体阈值；跨范围比较时颜色不具有固定 Token 含义。
- 无记录日显示虚线格，明确记录的零用量显示浅灰格；折线保留真实日期间隔，并在无记录处断开。范围内合计仅加总已有记录。
- 热力图使用固定尺寸格子、容器内横向滚动，默认滚到最近日期。悬停、触摸点击或键盘聚焦显示日期、Token、费用；方向键切换日期。手机折线在容器内滚动，避免压缩刻度至不可读。
- 非法日期和倒置区间直接提示，不静默交换或裁剪。全部历史仅限本地账本实际保有数据，不推测未采集记录。
- 单元测试覆盖日历筛选、跨月闰日、缺失/零用量、重复日聚合、颜色边界。浏览器检查涵盖视图切换、日期输入、偏好恢复、跨来源、方向键以及 320/390/1600 像素布局。
